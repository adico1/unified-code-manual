# UEM boundary in the converged application language

Canonical identity: `UEM-16-v0.1`.

UEM is the stable event-machine contract between seed-declared meaning and
physical targets. A host is not an application authority. Python, C, browser,
Tk, CLI and future targets must consume the same canonical operation, state,
event, boundary and result identities while remaining independently implemented.

The convergence track currently executes the specialized Python/Tk physical
projection. The independent Python/C UEM proof in `unified-code` is preserved
for the final migration; it must be connected to this newer declaration
language without copying results from one host to the other. Registration of
`UEM-16-v0.1` in ROOT is an identity pin, not a claim that this repository alone
already regenerates both hosts.

No runtime projection may load ROOT, a leaf seed, a registry or compiler code.
